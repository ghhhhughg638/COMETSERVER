# Comet Server

Comet Server 的 Windows x64 二进制发行版，附带中文管理后台。公开发行仓库只提供编译后的服务端程序、配置和网页，不包含项目源码。

## 下载

点击仓库页面的 **Code → Download ZIP**，或 `git clone` 整个仓库，解压到一个可写入的独立文件夹。

文件夹里需要保持这样的结构（EXE 和两个文件夹必须放在一起）：

| 内容 | 说明 |
| --- | --- |
| `CometServer.exe` | 服务端程序（单文件，已编译） |
| `config/` | 卡牌资料、规则、模板等外置配置，修改后可在后台一键热重载 |
| `admin_ui/` | 管理后台网页和图片 |
| `config.example.yaml` | 首次运行时用来生成 `config.yaml` 的模板 |
| `CONFIGURATION.md` | 配置文件字段说明 |

## 首次启动

1. 运行一次 `CometServer.exe`。如果旁边没有 `config.yaml`，程序会创建它并退出。
2. 编辑 `config.yaml`，检查监听地址和端口（默认 `0.0.0.0:5231`，会监听本机所有网络接口，请按实际部署设置防火墙）。
3. 创建主管理员（会提示输入至少 10 位密码）：

   ```
   CometServer.exe --create-admin 你的名字 --owner
   ```

4. 再次运行 `CometServer.exe` 启动服务，浏览器打开 `http://127.0.0.1:5231/admin/` 登录后台。

`config.yaml` 含有登录签名密钥等安全配置，不要公开上传或发送给他人。

## 管理后台

- 数据面板：在线人数曲线、峰值与低谷、记录间隔可调。
- 玩家管理：搜索玩家，查看战绩、卡组、好友、装备、登录 IP；修改名字、卡组、好友；封禁账号、禁言、禁止改名；同 IP 账号查询。
- 对局历史、兑换码、广播与关服通知、维护模式。
- 管理员账号：主管理员可新建账号、设置权限、暂停；所有后台操作写入操作日志。
- 配置编辑：规则、商店、会话模板等保存前有差异确认，规则类配置保存后立即生效；监听端口、数据库路径、登录签名密钥需要重启。

## 数据与日志

- 数据库：EXE 旁的 `data\comet.db`（SQLite）。文件不存在时程序会自动创建数据库和数据表；旧数据库中缺少的新字段会在启动时自动补上。运行时旁边会出现 `-wal`、`-shm` 文件，属正常现象。
- 运行日志：EXE 旁的 `app.log`；后台操作日志：`logs\admin_audit.jsonl`。
- 更新前请先停止服务，并备份 `config.yaml` 和 `data` 文件夹。更新时用新文件覆盖 `CometServer.exe` 和 `admin_ui`；`config` 里你改过的文件不要被覆盖。
